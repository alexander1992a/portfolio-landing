# PLAN: Portfolio Personal Trainee

## Fase 1: Estructura HTML base
- **Qué hace:** Crea el archivo `index.html` con el contenido semántico (presentación, sección de proyectos y contacto).
- **Archivos que toca:** `index.html`
- **Verificación:** Se abre en el navegador y muestra todo el texto y enlaces estructurados.

## Fase 2: Estilos CSS y diseño responsive
- **Qué hace:** Agrega estilos limpios con CSS (flexbox, diseño adaptable para celular y desktop).
- **Archivos que toca:** `style.css`
- **Verificación:** Se ve ordenado, legible y responsivo al cambiar el tamaño de la ventana.

## Fase 3: Publicación en Cloudflare Pages
- **Qué hace:** Conecta el repositorio a GitHub y despliega la landing en una URL pública.
- **Archivos que toca:** Ninguno (configuración en Cloudflare / Git)
- **Verificación:** La página carga online desde cualquier dispositivo mediante la URL pública.
